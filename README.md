# موقع مركز القادة لاستشارات التعليم وتطوير الأداء

موقع تعريفي عربي (RTL) لمركز القادة في الطرة، مبني بـ **HTML + CSS + JavaScript + Bootstrap 5**.
الموقع ثابت (Static) ولا يحتاج سيرفر أو قاعدة بيانات، ويعمل حتى بدون إنترنت.

---

## طريقة التشغيل

1. فك ضغط الملف.
2. افتح المجلد في **VS Code** (File ← Open Folder).
3. افتح `index.html` بإحدى الطريقتين:
   - الزر الأيمن ← **Open with Live Server** (إضافة Live Server)، أو
   - اضغط مرتين على `index.html` ليفتح في المتصفح مباشرة.

```
│   └── style.css         ← التصميم والألوان والتجاوب مع الجوال

```

## كيف أعدّل المحتوى؟

### رقم واتساب
في أول ملف `js/main.js`:

```js
const WHATSAPP_NUMBER = "962789898201";
```

اكتب الرقم بالصيغة الدولية بدون `+` وبدون صفر البداية. كل أزرار واتساب ونموذج التواصل تستخدم هذا المتغير.
رقم الهاتف الظاهر للعرض موجود أيضاً داخل `index.html` (ابحث عن `0789898201`) وفي روابط `tel:`.

### الأسعار
في `index.html` داخل قسم `id="pricing"`:
- أسعار المواد للصفوف 8 - 10 (بطاقتان: 10 د و 15 د).
- أسعار تحضير الامتحانات (ثلاث بطاقات حسب المرحلة).

سعر الحزمة الذكية (25 د) في قسم `id="package"`، ويتكرر في الأسئلة الشائعة وبطاقة البرنامج.

### فريق العمل
في قسم `id="team"`: كل شخص عبارة عن سطر واحد (عمود `col-...` يحتوي على `team-card`). انسخ سطراً وعدّل الاسم والدور والصفوف والحرف الأول داخل الدائرة.

### الصور
- ضع الصورة الجديدة داخل `assets/photos/` (يفضّل عرض لا يتجاوز 1200px لتبقى الصفحة سريعة).
- عدّل المسار داخل قسم `id="gallery"` (في `href` و `data-src` و `src`) وفي قسم `about` إذا لزم.

### الأسئلة الشائعة
قسم `id="faq"`: كل سؤال عنصر `accordion-item` يمكن نسخه وتعديله (انتبه لتغيير `id` و `data-bs-target` ليكونا فريدين).

### الألوان
في أعلى `css/style.css`:

```css
:root {
  --navy: #0f2447;   /* الكحلي */
  --gold: #c9a24b;   /* الذهبي */
  --cream: #faf7f0;  /* خلفية الصفحة */
}
```

### الشعار
استبدل `assets/logo.jpg` بشعار جديد بنفس الاسم (أو عدّل المسار في `index.html`).

## عدّاد الزيارات والتسجيل

- يعدّ الموقع: **إجمالي الزيارات**، **الزوار المختلفين** (كل متصفح مرة واحدة)، **ضغطات "سجّل الآن"** (كل الأزرار بهذا الاسم)، و**الطلبات المرسلة عبر النموذج**.
- الأعداد تُحفظ على خدمة **Abacus** المجانية (بدون حساب)، فتجمع كل الزوار من كل الأجهزة.
- لعرض الأعداد افتح `stats.html` (رابطها غير موجود في الموقع؛ افتحها بكتابة العنوان مباشرة، مثل `https://موقعك/stats.html`).
- لا تُحتسب زياراتك أثناء التجربة على جهازك (ملف محلي أو localhost). للتجربة أضف `?track=1` للرابط.
- اسم العدّاد (`COUNTER_NS`) في أول `js/counter.js`؛ غيّره إذا أردت البدء من الصفر.
- تنبيه: الأعداد غير محمية بكلمة مرور؛ أي شخص يعرف الاسم يستطيع قراءتها. هذا مناسب لإحصائيات بسيطة. للحصول على بيانات أدق (مصادر الزوار، الأجهزة...) يُنصح باستخدام Google Analytics.

## ملاحظات تقنية

- **Bootstrap 5.3.2** و **Font Awesome 6.5.1 (Free)** موجودان محلياً في `assets/vendor`، فالتصميم والأيقونات تعمل بدون إنترنت.
- **خط Cairo / Tajawal** يُحمَّل من Google Fonts عند توفر الإنترنت، وبدونه يستخدم الموقع خط النظام (Segoe UI / Tahoma).
- **نموذج التواصل** لا يُرسل بيانات لأي سيرفر؛ عند الضغط على "إرسال" يفتح واتساب برسالة جاهزة على رقم المركز.
- الموقع متجاوب مع الجوال والتابلت، ويحترم إعداد تقليل الحركة (`prefers-reduced-motion`).

## النشر (اختياري)

لنشر الموقع يكفي رفع محتوى المجلد كما هو إلى أي استضافة ملفات ثابتة (مثل GitHub Pages أو Netlify أو استضافة cPanel)، بحيث يكون `index.html` في الجذر.
